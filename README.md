# 🍋🍵🍅 Leaf Disease Detection with YOLOv8 and Flask

## 📌 Overview
This project implements a **deep learning-based leaf disease detection system** using **YOLOv8** for object detection and **Flask** for web deployment.  
It focuses on identifying diseases in **lemon, tea, and tomato leaves**, providing a simple web interface for real-time predictions.

---

## 🚀 Features
- **YOLOv8 model** trained for multi-class leaf disease detection.
- **Web application** built with Flask for easy interaction.
- **Image upload interface** for real-time disease prediction.
- **REST API endpoints** for integration with other applications.
- **Dataset preprocessing & augmentation** for robust training.
- **Evaluation metrics** (precision, recall, mAP) for performance tracking.

---

## 🛠️ Tech Stack
- **Python 3.9+**
- **YOLOv8 (Ultralytics)**
- **Flask**
- **OpenCV**
- **NumPy / Pandas**
- **Matplotlib / Seaborn**
